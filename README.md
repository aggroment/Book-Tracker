## Автор
Чолаку Роман

## Описание программы
Book Tracker — это десктопное приложение для управления списком прочитанных книг. Программа позволяет вести учёт прочитанной литературы, фильтровать книги по жанру и количеству страниц, а также сохранять данные в JSON формате.

### Возможности:
- 📝 Добавление книг с указанием названия, автора, жанра и количества страниц
- 🔍 Фильтрация книг по жанру и количеству страниц (>, >=, =, <, <=)
- 📊 Статистика по прочитанным книгам (общее количество, страниц, среднее, популярные жанры)
- 💾 Автоматическое и ручное сохранение данных в JSON
- 🗑️ Удаление книг через контекстное меню
- ✅ Валидация ввода (непустые поля, корректное число страниц)
- 📅 Автоматическая запись даты добавления

## Как запустить приложение

- Python 3.6 или выше
- Tkinter (входит в стандартную поставку Python)

# 2. Откройте терминал/командную строку в папке с файлом

# 3. Запустите программу
